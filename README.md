# Highlands Coffee Sales Management System

## Overview
Hệ thống quản lý bán hàng được xây dựng nhằm hỗ trợ quản lý đơn hàng, sản phẩm, doanh thu và tồn kho cho cửa hàng Highlands Coffee.

Project tập trung vào phân tích quy trình nghiệp vụ, mô hình hóa hệ thống và xây dựng giải pháp hỗ trợ vận hành hiệu quả hơn.
